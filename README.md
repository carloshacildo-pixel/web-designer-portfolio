# Web Designer Portfolio

A professional portfolio website showcasing web design projects, skills, and services.

## 🌟 Features

- **Responsive Design** - Works perfectly on all devices (desktop, tablet, mobile)
- **Modern UI/UX** - Clean and professional design with smooth animations
- **Project Showcase** - Beautiful portfolio grid displaying design projects
- **Services Section** - Highlight your expertise and offerings
- **Skills Display** - Organized skills and tools you're proficient with
- **Contact Form** - Allow potential clients to reach out directly
- **Social Links** - Connect with your professional profiles
- **Smooth Scrolling** - Enhanced navigation experience

## 🚀 How to Use

### Option 1: GitHub Pages (Free Hosting)

1. Go to your repository settings
2. Scroll down to **Pages** section
3. Under "Source", select `main` branch
4. Click **Save**
5. Your site will be available at: `https://carloshacildo-pixel.github.io/web-designer-portfolio`

### Option 2: Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. Edit files as needed
4. Push changes to GitHub

## 📝 Customization

### Update Your Information

**In `index.html`:**
- Change the name "Carlos Hacildo" in the navigation and footer
- Update the About section with your bio
- Modify the contact links and email
- Update social media links

**In `styles.css`:**
- Change the color scheme (currently purple/blue gradient)
- Adjust font sizes and spacing
- Customize breakpoints for responsive design

### Add Your Own Projects

Replace the portfolio images with your own:

```html
<div class="portfolio-item">
    <img src="YOUR_IMAGE_URL" alt="Project Name">
    <div class="portfolio-overlay">
        <h3>Project Name</h3>
        <p>Project Description</p>
    </div>
</div>
```
